**lsa 0.3.1 — less formatting and artwork work.**

- Long listings reuse metadata formatting storage and borrow cached owner/group
  names, reducing temporary allocations while preserving field alignment.
- Text icons, filenames and type markers stream without an assembled label;
  compact columns keep complete Unicode widths and the same color/link framing.
- Built-in artwork computes polygon crossings once per row, with bounded stack
  scratch and pixel-for-pixel tests against the previous rasterizer.
- The headless terminal helper drains output after observing child exit, fixing
  an intermittent loss of the final output that could cause spurious test failures.

These changes preserve listing order, output bytes, image pixels, preview limits,
supported formats and opt-in cache behavior. No dependencies or workers were added.
Paired local measurements show about 4–7% less CPU for selected styled/long
listings and 4.8–7.5% less artwork CPU; plain output and image decoding are
essentially unchanged. Validation passes 50 unit tests, 13 macOS CLI tests, two
artwork-example tests, three release-tooling tests, 196 headless terminal scenarios,
strict lint and extracted-package checks.
See the [paired measurements](https://github.com/yungibly/lsa/blob/v0.3.1/benchmarks/README.md)
for application/PTY cost; terminal rendering is not measured.

Install or update:

```sh
brew install yungibly/tap/lsa
# Existing installation:
brew update && brew upgrade lsa
```

Checksummed standalone binaries cover Apple Silicon/Intel macOS 14+ and
ARM64/x86-64 Linux. Output stays in scrollback and returns to the shell.
The pending user Ghostty pass for the v0.3.0 default details and AM/PM appearance
remains separate from these automated checks.
