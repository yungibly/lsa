**lsa 0.2.0 — larger galleries, adjustable thumbnails, SVG previews.**

- Preview up to **256 images by default**, with `--preview-limit=N` accepting
  values through 4,096. All entries remain visible when budgets are spent.
- Choose grid height with **`--thumbnail-size=1..12`**, in terminal-row increments.
  The default stays 3; width/spacing adjust and previews shrink to fit the terminal.
- Combinations such as `--grid --header` now explain which layout takes precedence.
  Help includes examples and marks options that imply a long listing.
- Added **SVG vector artwork and ICO** previews. SVG paths, shapes, gradients and
  clipping work within bounded resources; text, embedded images and complex effects
  fall back to artwork. WebM still uses a media icon.
- Reduced source/encoding copies and rotate JPEGs after thumbnailing. A generated
  6.4 MP rotated JPEG measured 25% faster with 47% less peak process memory.
  Built-in artwork uses less CPU while producing identical pixels.

Output continues to print directly into terminal scrollback and return to the shell.
The user verified the new behavior in Ghostty; benchmarks measure the application
and drained PTY transport, not terminal rendering. Details and conditions are in the
[benchmarks](https://github.com/yungibly/lsa/blob/v0.2.0/benchmarks/README.md) and
[compatibility notes](https://github.com/yungibly/lsa/blob/v0.2.0/docs/compatibility.md).

The opt-in thumbnail cache now uses the v2 namespace; old cache files are left alone.
`--clear-cache` clears the current namespace. Caching remains off by default.

Install or update after the release workflow finishes:

```sh
brew install yungibly/tap/lsa
# Existing installations:
brew update && brew upgrade lsa
```

Standalone checksummed binaries are attached for Apple Silicon/Intel macOS 14+
and ARM64/x86-64 Linux (static musl). Verify the matching archive against
`SHA256SUMS`, extract it, and place `bin/lsa` on PATH.
