**lsa 0.3.0 — everyday details with less listing overhead.**

- Terminal text now defaults to long form: permissions, readable size, owner and
  local modification time. Image-heavy and small mixed listings still switch to
  inline grids automatically. Pipes still default to plain names.
- `-C` / `--columns` selects compact text columns. Explicit `-l`, `--header` and
  `--fields` continue to select long form, including in image directories.
- `--12-hour` displays modification times with AM/PM. Midnight, noon, local dates,
  daylight-saving changes and column/thumbnail alignment are covered by tests.
- Smaller metadata records, one local-time conversion per entry, borrowed safe
  filenames and fewer permission-formatting allocations reduce application cost.

In paired macOS measurements, 10,000-entry long listings with distinct timestamps
take about half the time and use about 14% less peak memory. Repeated-timestamp
listings also improve; image decoding and graphics traffic are unchanged. These
are application/PTY measurements, not terminal rendering measurements. The new
long default prints more text than compact columns; use `-C` for the smaller view.
See the [measurement report](https://github.com/yungibly/lsa/blob/v0.3.0/benchmarks/README.md).

Local validation includes 47 unit tests, 13 macOS CLI tests, an artwork-example
test, three release-tooling tests, 195 headless terminal scenarios, strict lint
and extracted-package checks. Real Ghostty appearance for the new defaults and
AM/PM option awaits a fresh user pass; existing image output is unchanged.

Install or update:

```sh
brew install yungibly/tap/lsa
# Existing installation:
brew update && brew upgrade lsa
```

Standalone checksummed binaries cover Apple Silicon/Intel macOS 14+ and
ARM64/x86-64 Linux. Download the matching archive and verify it against
`SHA256SUMS` before extraction. Output stays in scrollback and returns to the
shell; preview limits, opt-in caching and supported image formats are unchanged.
