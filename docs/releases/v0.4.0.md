**lsa 0.4.0 — clickable filenames by default.**

- Local terminal listings automatically link filenames using OSC 8, including
  details, compact columns and wrapped thumbnail labels.
- Pipes and redirected files keep plain output. Auto also skips empty/unset or
  dumb `TERM` and detected SSH sessions.
- `--hyperlink=auto|always|never` controls links. Bare `--hyperlink` forces them;
  `--no-hyperlink` disables them. The last hyperlink option wins, and `NO_COLOR`
  still controls only color.
- File URLs include the local hostname and safely encode raw filename bytes.
  Symlinks retain their own paths. Hostname/current-directory lookup failures
  leave usable text; forcing remote links depends on terminal support.
- The hostname and working-directory prefixes are encoded once, and filename
  paths stream without temporary per-entry URL allocations or extra file reads.

Listing order, preview budgets, image pixels and opt-in caching are unchanged.
No dependencies, workers or terminal input handling were added. Automated tests
cover output bytes, layout, redirection and SSH environment policy; real Ghostty
click behavior and SSH/multiplexer opening remain unverified.
Local validation passes 51 unit tests, 15 macOS CLI tests, two artwork-example
tests, three release-tooling tests and 234 headless terminal scenarios, plus
strict lint and extracted-package checks.
See [application measurements](https://github.com/yungibly/lsa/blob/v0.4.0/benchmarks/README.md)
for overhead; terminal rendering is not measured.

Install or update:

```sh
brew install yungibly/tap/lsa
# Existing installation:
brew update && brew upgrade lsa
```

Checksummed standalone binaries cover Apple Silicon/Intel macOS 14+ and
ARM64/x86-64 Linux. Output stays in scrollback and returns to the shell.
